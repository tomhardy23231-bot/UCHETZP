# Архив прошивок — точки отката

Замороженные копии рабочих версий. Нужны, чтобы откатиться, если новая прошивка
окажется хуже старой. **Эти файлы не редактируем** — рабочий исходник один:
[`../scanner_firmware.cpp`](../scanner_firmware.cpp).

| Файл | Что это | Когда брать |
|---|---|---|
| `scanner_firmware_v1.0_ORIGINAL.cpp` | Ровно то, что лежало в репозитории (`git 8139b5e`). Шлёт отметки на мёртвый `uche12tzp.vercel.app`. | Только для истории — отметки с ней теряются. |
| `scanner_firmware_v1.1_url-fix.cpp` | То же самое, но с адресом `zp.haskyhub.com`. **Последняя заведомо рабочая версия.** | Это и есть точка отката. |

## Как откатиться

```bash
cp firmware/archive/scanner_firmware_v1.1_url-fix.cpp firmware/scanner_firmware.cpp
```

Дальше собрать в Arduino IDE / PlatformIO и залить по OTA (хост `HARIZMA-SCANNER`)
или по USB. Сканер должен не спать — будни 06:00–19:30.

> Откат «из админки» работает не всегда: если новая прошивка не выходит на связь,
> команду на обновление она не получит. Тогда только OTA из локальной сети или USB.

Все версии, включая эту, лежат и в истории git — архив нужен для того, чтобы
нужный файл можно было взять не разбираясь в коммитах.
