# Прошивка сканера HARIZMA (ESP32)

**`scanner_firmware.cpp` — актуальная рабочая прошивка** системы учёта посещаемости
UCHETZP (по состоянию на 2026-04-29). Это эталон-источник: при заливке всегда брать его.

Все более ранние черновики (`firmware_v3*`, `firmware_fixed*`, `rfid_attendance_v3.*`)
— устаревшие и **нерабочие**: они шлют данные на мёртвый домен `uchetzp.vercel.app` (404).

## Ключевые параметры

| Параметр         | Значение                                                  |
|------------------|-----------------------------------------------------------|
| Платформа        | ESP32 (Arduino framework)                                 |
| Сервер (API)     | `https://uche12tzp.vercel.app/api/attendance/bulk-scan`   |
| Формат отправки  | `{"scans":[{"card_id":"...","timestamp":"..."}]}`         |
| RFID-ридер       | UART (Serial2), пин RX = 16, 9600 8N1                     |
| Экран            | ST7735 1.44" (SPI)                                        |
| Подсветка        | WS2812B, 12 диодов, пин 15                                |
| Звук             | I2S (BCLK 5 / LRC 6 / DOUT 7), бипы успех/ошибка/навигация |
| Wi-Fi            | WiFiManager (портал настройки `HARIZMA_SETUP`)            |
| Время            | синхронизация по NTP                                       |
| Обновление       | OTA по сети (хост `HARIZMA-SCANNER`)                       |
| Офлайн-режим     | очередь сканов в LittleFS (`/offline.jsonl`), досыл пачкой |
| Энергосбережение | deep sleep ночью и на выходные                            |

## Что делает устройство
- Читает RFID-карты и регистрирует отметки прихода/ухода.
- Дисплей с UI: главный экран с часами, меню, громкость, настройка Wi-Fi.
- При отсутствии интернета отметки копятся в `offline.jsonl` и досылаются при появлении связи.

## Сборка
Открыть `scanner_firmware.cpp` в Arduino IDE / PlatformIO.

Нужные библиотеки: `WiFi`, `WiFiClientSecure`, `HTTPClient`, `LittleFS`, `FastLED`,
`Adafruit_GFX`, `Adafruit_ST7735`, `U8g2_for_Adafruit_GFX`, `WiFiManager`, `ArduinoOTA`,
`esp_task_wdt`, драйвер `driver/i2s_std.h`.

## Важно
Прошивка обновляется по воздуху (OTA), поэтому версия, физически залитая в сканер,
может отличаться от этого файла. Этот файл — эталон-источник.
